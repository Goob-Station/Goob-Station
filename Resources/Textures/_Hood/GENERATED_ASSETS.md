# Hood generated-asset provenance

The files below are original project artwork generated with OpenAI imagegen on
2026-08-17 and released with this project under CC-BY-SA-3.0. They were
post-processed into 32x32 SS14 RSI states by the scripts in `Tools/_Hood`.

## Grounded long guns

- `Objects/Weapons/Guns/rook_c9.rsi` — source generation
  `exec-9b9e8240-7845-4cd8-9a1e-00d15b98f268.png`; prompt requested an
  original, brand-free compact charcoal urban carbine with a muted teal accent,
  isolated inventory/action/empty and directional game views on transparency.
- `Objects/Weapons/Guns/arroyo_r12.rsi` — source generation
  `exec-2054223c-53f2-469f-a817-e4fbf80ab3e6.png`; prompt requested an
  original, brand-free civilian-pattern graphite rifle with brown synthetic
  furniture and inventory/action/empty and directional views on transparency.
- `Objects/Weapons/Guns/mesa_p12.rsi` — source generation
  `exec-23ff38b6-f61b-4e52-ad44-035efbc9390b.png`; prompt requested an
  original, brand-free matte-blue utility pump shotgun with dark-sand furniture
  and isolated inventory/action and equipped views on transparency.

Only the isolated weapon concepts were retained. Generated presentation
backgrounds and incidental figures were discarded. Rebuild with
`Tools/_Hood/Build-HoodLongGunRsis.py` and the three source atlases.
